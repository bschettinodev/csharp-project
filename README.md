# Finance Tracker API

Backend API for a personal finance management system built with ASP.NET Core, Entity Framework Core and PostgreSQL.

This project provides a structured way to manage financial data such as expenses, categories and accounts, with support for future analytics and reporting features.

## Overview

The API is designed to handle manual financial tracking. Users can register transactions, organize them into categories and associate them with accounts. The system is intended to support financial insights such as monthly summaries and category-based analysis.

This project is being developed as a backend-focused application to practice real-world API design, data modeling and financial domain logic.

## Tech Stack

- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Docker

## Features

- Manage financial transactions (income and expenses)
- Organize transactions by category
- Support for multiple accounts (bank, wallet, credit card)
- Monthly financial tracking
- Foundation for dashboard and analytics
